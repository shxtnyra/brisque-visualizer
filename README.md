# BRISQUE Visualizer

Electron + Vite приложение для визуализации качества изображений с помощью BRISQUE.

## Требования

- Node.js >= 18.0.0
- npm >= 10.0.0

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Дополнительные команды сборки

```bash
npm run build:dir
npm run build:win
npm run build:linux
```

## Запуск

```bash
npm run dev
```

## Предпросмотр собранного приложения

```bash
npm run start
```

## Проверки и форматирование

```bash
npm run lint
npm run lint:fix
npm run prettier:check
npm run typecheck
npm run check
npm run clean
```
